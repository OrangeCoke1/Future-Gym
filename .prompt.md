# Task: Hand / finger tracking with a panel switch

User: "有没有能识别更细致的方法，比如手指之类的" → "在面板加个开关".

## Plan
1. Model: add MediaPipe `hand_landmarker.task` (float16 v1, 7.8 MB) to `public/mediapipe/` (same tasks-vision 0.10.14 wasm).
2. `src/pose/hands.js` (new): `loadHandLandmarker()` (VIDEO, 2 hands, GPU→CPU), `createHands()` state per figure side
   {lm2d, grip, across, gesture, seen}, `ingestHands()` (assign each detected hand to the person's left/right wrist by 2D distance
   to the pose wrists 15/16, fallback handedness; mirror like the body), grip from fingertip/knuckle distances, palm "across"
   axis for wrist roll, simple gestures (握拳 / 张开 / 比 V / 点赞 / 指), `drawHands()` for the camera window.
3. `src/engine/camera.js`: lazy-load the hand model when switched on; run it on the same frames after the pose; draw over the
   pose skeleton; ask for 1280×720 while hands are on (restart the stream on toggle) since fingers are small at full-body distance.
4. `src/pose/camera.js` `camSolve`: when a hand was seen in the last 0.3 s, its palm axis sets the thumb point (wrist roll) and
   `sol.grip = {L, R}` carries the grip.
5. Rendering: `hand.js` `applyFist` per hand (L/R grip), `stage.js` smooths each hand's grip = max(dumbbell, tracked grip),
   `particles.js` / `bodyModel.js` pass it through.
6. Engine `setHands(on)`, `S.handG` (gesture labels) mirrored to `live` for the camera window title.
7. Settings `camHands` (localStorage `stick.camHands`, default off), panel switch in 摄像头跟随 with a hint; i18n ja/en.
8. Checks: lint, build, node test on grip / gesture classification with synthetic hands, headless smoke test (toggle, no errors).
