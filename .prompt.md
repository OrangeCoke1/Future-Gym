# Task: One-link preview (Vercel)

User: "能不能换个更方便的方法 … 预览" — downloading and unzipping a preview package after every change is clumsy.

## Analysis
- The repo is private, so GitHub Pages would need GitHub Pro (or making the repo public).
- Camera access and MediaPipe need https (or localhost). Claude artifacts can't use the camera (sandboxed frame).
- Vercel's free tier deploys private GitHub repos over https, redeploys on every push to main, and gives each PR its own preview URL.

## Plan
1. Add `vercel.json` at the repo root: install and build in `stickman-preview/`, output `stickman-preview/dist`, no framework preset
   (so the user doesn't have to set a root directory).
2. The user imports the repo once at vercel.com/new (GitHub sign-in); nothing else needs configuring.
3. Log to `.dev_log`; mention the preview URL in CLAUDE.md once known.
