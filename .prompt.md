# Task: Body tracking misaligned ("错位") — high-accuracy model + 2D/3D fusion

User: "我觉得身体识别还是不够好" → the problem is "错位" (the figure's limbs don't line up with the person).

## Analysis
- The figure takes bone directions only from MediaPipe *world* landmarks. Their x/y come from a cropped, regressed
  3D estimate and often disagree with the person in the image by several degrees (the camera window, drawn from the
  2D image landmarks, looks right while the figure is off). The 2D image landmarks are the most accurate signal for
  the in-plane direction; world z is the only usable depth.
- The bundled model is `pose_landmarker_full`; MediaPipe's `heavy` model is noticeably more accurate (esp. depth),
  at more compute.

## Plan
1. Add `public/mediapipe/pose_landmarker_heavy.task` (float16 v1, same tasks-vision 0.10.14).
2. `loadLandmarker(model)` picks full / heavy. Setting `camModel` ('heavy' | 'full', default 'heavy', `stick.camModel`),
   panel switch 识别精度 高精度 / 标准 in 摄像头跟随, engine/camera `setModel()` reloads the landmarker on the fly.
3. 2D/3D fusion in `camIngest`: per frame scale s (m per image unit) = world torso xy lengths / image torso lengths
   (shoulders, hips, shoulder-mid → hip-mid; only when all four torso points are confident; low-passed). Each point's
   x/y = image position relative to the hip midpoint × s (aspect-corrected), blended 80 % with world x/y; z = world z.
   Falls back to pure world landmarks when the torso is not seen.
4. Checks: node test (fusion equals world when consistent; follows image when world xy is rotated), lint, build,
   headless smoke (switch model, no errors). Docs: CLAUDE.md, README, .dev_log.
