# Task: Make the figure follow squats faster, measured on recorded videos

User: "我需要新的动作应该怎么做,我已经录好了十个不同人的深蹲" / "我是想让他的数据能拟合的更快".
Squat already exists (ACT.squat, FIT squat rule). Goal: lower following latency during squats, validated on the
user's 10 recorded people.

## Plan
1. `tools/pose-extract.mjs`: video → per-frame MediaPipe landmarks (same model and settings as the app) via ffmpeg +
   headless Chromium; JSON per video.
2. `tools/follow-bench.mjs`: replay through camIngest / camPredict on a simulated clock (camera + inference delay,
   60 Hz render); compare with zero-delay smoothed truth; lag / error / jitter / overshoot per joint angle; sweep.
3. With the real videos: measure the current lag, then add squat-aware prediction (bounded by the person's own rep
   range so a larger lead does not overshoot) and/or squat-specific filter settings; keep only what the bench shows
   is faster without more jitter.
4. README section, lint, build, PR, merge.
