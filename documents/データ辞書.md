## 凡例

- **型**：JavaScript の値の型で書く。IndexedDB はスキーマで型を強制しないため、型と制約はアプリケーション側で保証する。
  - `number`：数値
  - `string`：文字列
  - `object`：オブジェクト
- **日時**：すべてエポックミリ秒（1970-01-01 UTC からの経過ミリ秒）の `number` で保存する。
- **PK / FK / UK**：主キー / 外部キー / ユニークキー。
- **必須**：○ = 必ず値がある。
- **IDX**：○ = インデックスあり。

| 1 | ユーザー ID | `id` | number | 1〜 | ○ | | | ○ | ○ | 自動採番 | |

## 2. workouts（トレーニング）

ユーザーが 1 回の訪問で行ったトレーニング。ログイン中のユーザーが最初の種目を記録したときに作成する。

| No | 論理名 | 物理名 | 型 | 桁・範囲 | PK | FK | UK | 必須 | IDX | 初期値 | 説明 |
|---|---|---|---|---|---|---|---|---|---|---|---|
| 1 | トレーニング ID | `id` | number | 1〜 | ○ | | | ○ | ○ | 自動採番 | |
| 2 | ユーザー ID | `userId` | number | | | ○ | | ○ | ○ | | `users.id` を参照 |
| 3 | 開始日時 | `startedAt` | number | | | | | ○ | ○ | 最初の種目の記録時刻 | 複合インデックス `[userId+startedAt]` の第 2 キー |
| 4 | 終了日時 | `endedAt` | number | ≥ startedAt | | | | ○ | | `startedAt` と同じ | 最後の種目の記録時刻。種目を記録するたびに更新する |
| 5 | 種目数 | `setCount` | number | 0〜、整数 | | | | ○ | | 0 | 種目を記録するたびに 1 増やす |
| 6 | 推定消費エネルギー | `kcal` | number | 0〜、整数 | | | | ○ | | 0 | 単位 kcal。この訪問での累計推定値を四捨五入した値 |
| 7 | プロフィール（記録時点） | `profile` | object | | | | | ○ | | 作成時のプロフィール | 構造は「5. 共通構造」を参照。後でプロフィールを変えても変わらない |
| 8 | メモ | `note` | string | 0〜200 文字 | | | | ○ | | `''`（空文字） | ユーザーが入力する |

## 3. sets（種目記録）

1 回のトレーニングの中で行った種目ごとの回数。種目またはデータソースを切り替えたときに、直前の種目を 1 件記録する。

| No | 論理名 | 物理名 | 型 | 桁・範囲 | PK | FK | UK | 必須 | IDX | 初期値 | 説明 |
|---|---|---|---|---|---|---|---|---|---|---|---|
| 1 | 記録 ID | `id` | number | 1〜 | ○ | | | ○ | ○ | 自動採番 | |
| 2 | トレーニング ID | `workoutId` | number | | | ○ | | ○ | ○ | | `workouts.id` を参照 |
| 3 | ユーザー ID | `userId` | number | | | ○ | | ○ | ○ | | `users.id` を参照。所属トレーニングの `userId` と同じ値（集計用の冗長項目） |
| 4 | 種目コード | `action` | string | | | | | ○ | ○ | | 「6.1 種目コード」を参照 |
| 5 | 種目名 | `name` | string | | | | | ○ | | | 種目の中国語の原文（例：`深蹲`）。画面では表示言語に翻訳する |
| 6 | 回数 | `n` | number | 1〜、整数 | | | | ○ | | | 回数または歩数。0 回の種目は記録しない |
| 7 | 単位 | `unit` | string | | | | | ○ | | | 「6.2 単位」を参照 |
| 8 | データソース | `src` | string | | | | | ○ | | | 「6.3 データソース」を参照 |
| 9 | 記録日時 | `t` | number | | | | | ○ | | 記録時刻 | |

## 4. インデックス一覧

| No | テーブル | インデックス | 種類 | 項目 | 用途 |
|---|---|---|---|---|---|
| 1 | users | 主キー | 主キー（自動採番） | `id` | |
| 2 | users | `username` | ユニーク | `username` | ログイン時の検索、重複登録の防止 |
| 3 | workouts | 主キー | 主キー（自動採番） | `id` | |
| 4 | workouts | `userId` | 通常 | `userId` | ユーザー単位の全削除 |
| 5 | workouts | `[userId+startedAt]` | 複合 | `userId`, `startedAt` | ユーザーの履歴を新しい順に取得する |
| 6 | sets | 主キー | 主キー（自動採番） | `id` | |
| 7 | sets | `workoutId` | 通常 | `workoutId` | トレーニングに含まれる種目の取得、カスケード削除 |
| 8 | sets | `userId` | 通常 | `userId` | ユーザー別・種目別の累計、ユーザー単位の全削除 |
| 9 | sets | `action` | 通常 | `action` | 種目別の検索・集計 |

Dexie でのスキーマ定義（`stickman-preview/src/db/db.js`）：

```js
db.version(1).stores({
  users: '++id, &username',
  workouts: '++id, userId, [userId+startedAt]',
  sets: '++id, workoutId, userId, action'
});
```

## 5. 共通構造

### プロフィール（`users.profile`、`workouts.profile`）

| No | 論理名 | 物理名 | 型 | 範囲 | 初期値 | 説明 |
|---|---|---|---|---|---|---|
| 1 | 体重 | `w` | number | 30〜200 | 65 | 単位 kg |
| 2 | 年齢 | `age` | number | 10〜99 | 30 | 単位 歳 |
| 3 | 性別 | `sex` | string | 「6.4 性別」を参照 | `'m'` | |

消費エネルギーの推定（MET 法、または心拍数による Keytel ら 2005 の式）にだけ使う。

## 6. コード定義

### 6.1 種目コード（`sets.action`）

記録されるのは、回数を数える種目だけである（「待機」「ターン」は回数を数えないため記録しない）。

| コード | 種目名（日本語） | 種目名（保存値） | 単位 |
|---|---|---|---|
| `walk` | ウォーキング | 走路 | 歩 |
| `wave` | 手を振る | 挥手 | 回 |
| `squat` | スクワット | 深蹲 | 回 |
| `lunge` | ランジ | 弓步 | 回 |
| `jog` | ジョギング | 慢跑 | 歩 |
| `high` | もも上げ | 高抬腿 | 歩 |
| `jacks` | ジャンピングジャック | 开合跳 | 回 |
| `curl` | アームカール | 弯举 | 回 |
| `press` | ショルダープレス | 推举 | 回 |
| `lateral` | サイドレイズ | 侧平举 | 回 |

### 6.2 単位（`sets.unit`）

| 保存値 | 意味 |
|---|---|
| `次` | 回 |
| `步` | 歩 |

### 6.3 データソース（`sets.src`）

| 保存値 | 意味 |
|---|---|
| `演示` | デモ（お手本アニメーションの回数） |
| `摄像头` | カメラ（カメラで認識した本人の回数） |

### 6.4 性別（`profile.sex`）

| 保存値 | 意味 |
|---|---|
| `m` | 男性 |
| `f` | 女性 |

## 7. localStorage（参考）

IndexedDB 以外にブラウザに保存する、DB に関係する値。

| キー | 型 | 説明 |
|---|---|---|
| `stick.user` | number \| null | ログイン中のユーザー ID（`users.id`）。ログアウト中は `null`。再読み込み後もログイン状態を保つために使う |
| `stick.profile` | object | 未ログイン時のプロフィール（構造は「5. 共通構造」と同じ） |
